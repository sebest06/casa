# Tareas de la casa

Página para organizar las tareas de la casa por semana y por persona.
Se publica con GitHub Pages; los datos viven en un repositorio privado aparte (`casa-datos`)
y se leen/guardan desde la página con un token de GitHub (botón **GitHub**).

También funciona sin internet (usa la copia guardada en el dispositivo) y se puede abrir
`index.html` directamente con un CSV local (botón **Abrir CSV**).
